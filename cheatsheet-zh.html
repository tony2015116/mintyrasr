遗传参数 按组分名字定位

varcomp 每一行与 names(fit$vparameters)（即 vpredict 的 V）对应，并分为 遗传 / 随机 / 残差 和 方差 / 协方差 / 相关。尺度参数 units!R（在 units!units 之后）和 units:trait!R 不使用。

参数公式
h2iVai / 性状 i 的所有方差之和
rgCova / √(Va1Va2)；cor* 结构直接取相关
rp所有协方差之和 / √(Vp1Vp2)；相关项按 r√(V1V2) 换算
# us G + us R
h2_value1 = V1/(V1 + V5); rg = V2/sqrt(V1 * V3)
# corgh G + diag R
h2_nls = V2/(V2 + V5); rg = V1
# 自定义公式（先看 res$vc_index）
asr_gblup(..., random = ~ ide(id),
  vpredict = list(rep = rep ~ (V1 + V2)/(V1 + V2 + V3)))
fa() / rr() 以及多个遗传项（母体效应 str()）：在 vpredict 中自己写公式。

检验 lrt.asreml(boundary = FALSE)

参数简化模型输出
test_rg = TRUE遗传项 idh(trait)rg_lrt rg_p

test_rp：两性状是否有任何相关（所有协方差 = 0），不是单独检验 rp = 0。

交叉验证 每折

cv_vc每折的方差组分
"fixed"全数据估计值，Constraint = "F"，maxit = 1 — 快，有轻微泄漏
"warm"以全数据值为初值重新估计
"estimate"从默认初值重新估计 — 无泄漏，最慢
指标定义
rel1 − PEV / ((1 + F) Va)，Va 取当折；低于 min_rel 的不用
par(y, GEBV)，预测能力
accuracypa / √h2，h2 用全数据估计值
slopeb(y ~ GEBV)，理想值 1

元素内容

paramh2、rg、rp（含 SE）、formulas、converge、loglik、boundary、检验
accuracy重复 × 折 × 性状：n、pa、accuracy、slope、va、h2_full
summarypa / accuracy / slope：n、mean、sd、se
pred验证个体：obs、gebv、pev、inb、rel

检查与提示

  • 警告：ginv 无 INVERSE 属性；个体不在 ginv 中；组分在边界上（B，也记在 param$boundary）；gammaPar = TRUE；未收敛
  • ASReml 默认 maxit = 13、workspace = "128mb"，两性状 GBLUP 不够用
  • max_update = 2 → 对未收敛模型调用 update()
  • on_error = "warn"：某次拟合失败结果为 NA，循环继续
  • 不保存模型对象 → 内存占用低
  • 其他 asreml() 参数：asreml_args = list(ai.sing = TRUE)
