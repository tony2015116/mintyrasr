Genetic parameters by component name

Each varcomp row is matched to names(fit$vparameters) (= V of vpredict) and classified as genetic / random / residual and var / cov / cor. Scale rows units!R (after units!units) and units:trait!R are skipped.

parameterformula
h2iVai / (all variances of trait i)
rgCova / √(Va1Va2); cor* → the correlation
rpΣ covariances / √(Vp1Vp2); cor term → r√(V1V2)
# us G + us R
h2_value1 = V1/(V1 + V5); rg = V2/sqrt(V1 * V3)
# corgh G + diag R
h2_nls = V2/(V2 + V5); rg = V1

  vpredict = list(rep = rep ~ (V1 + V2)/(V1 + V2 + V3)))

Cross-validation per fold

cv_vcvariance components in each fold
"fixed"full-data values, Constraint = "F", maxit = 1 — fast, slight leakage
"warm"re-estimated, starting from full-data values
"estimate"re-estimated from defaults — no leakage, slowest
measuredefinition
rel1 − PEV / ((1 + F) Va), Va of the fold; not filtered in CV (cv_min_rel = -Inf); fold needs ≥ min_n = 10
par(y, GEBV)
accuracypa / √h2, full-data h2
slopeb(y ~ GEBV), ideally 1

Checks & tips

  • warnings: no INVERSE attribute; IDs not in ginv; components at the boundary (B, also param$boundary); gammaPar = TRUE; no convergence
  • ASReml defaults maxit = 13, workspace = "128mb" are too small for two-trait GBLUP
  • one progress line per fit: status, iterations, time, ~time left (ASReml monitor off: asreml_trace = FALSE)
  • max_update = 2 → update(); still not converged: nonconv = "skip" (CV rows skipped) or "keep"
  • errors & non-convergence → status + $log, the loop goes on; rows with status ≠ ok are not in summary
  • keep the computer awake: sleep shows up as a long pause
  • models are not kept → low memory
  • asreml_args = list(ai.sing = TRUE) for other asreml() arguments
