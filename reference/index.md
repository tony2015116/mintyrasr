## GBLUP with ASReml-R

Parameter estimation and cross-validation for one scenario, or for all
scenarios of mintyr::cv_scenarios() in one call.

- [`asr_gblup()`](https://tony2015116.github.io/mintyrasr/reference/asr_gblup.md)
  : GBLUP parameter estimation and cross-validation with ASReml-R

- [`asr_scenarios()`](https://tony2015116.github.io/mintyrasr/reference/asr_scenarios.md)
  :

  Run several GBLUP scenarios from
  [`cv_scenarios()`](https://tony2015116.github.io/mintyr/reference/cv_scenarios.html)
